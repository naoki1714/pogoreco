# テスト用ログ

実ログはユーザー名・自分の Steam ID・PC の情報（GPU 名・ゲームの場所）をダミーに置き換え、他のプレイヤーの名前や Steam ID を含む行（ロビーの出入りなど）を取り除いてある。

- `menu-only.txt` — 実ログ。メニュー画面だけで終了した回。
- `map1-finish.txt` — 実ログ。Map 1 を登頂 → リセット → 再挑戦中（プレイ中に取得したので終了行は無い）。ゲームの「スプリット表示」はオフ。
- `map1-map2-progress.txt` — 実ログ。Map 1 の途中から再開 → Map 2 へ。到達%（`progress(…)`）の行がある。
- `best-map1.replay` — 実ファイル。Map 1 の自己ベスト（12:06.781）のリプレイ。ヘッダーの Steam アカウント番号（int32[8], [9]）は 0 にしてある。
- `gameplay-provisional.txt` — **暫定**。区間通過（`playerCheckpointDo`）と `update splits` の行は既存ツールの正規表現から組み立てたもので、実物ではない。スプリット表示をオンにした実ログが取れたら差し替える。
